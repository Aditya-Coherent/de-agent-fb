7 · Source audit — every citation re-opened and checked

After the model was built, each cited page was re-opened and checked for the number attributed to it. The failures are published here rather than quietly patched, because a method that cannot catch its own bad citations is not worth trusting with the good ones.

Root cause — worth building a guard against
All three failures share one cause: the figure was taken from a search-result summary that aggregates several vendor pages, then attributed to a single URL from that result set. The summary is itself a model reading pages — so the citation pointed somewhere the number had never been. Rule that follows: a number may only be tagged T1–T3 if it was read from a page that was actually fetched. Search may find candidates; it may never be the source of record.

8 · The escalation ladder — what to do when there is no source

Every input is pushed as far up this ladder as the evidence allows, and the tier it lands on is recorded. An LLM never produces a magnitude at any rung. The bottom rung is a declared, bounded, simulated parameter — which is a very different object from a guess, because it has a range, an owner, and a measurable influence.

Rung 1 · T1

Fetch it

Public API, machine-reproducible. Comtrade trade flows and World Bank population re-derive on every run of the build script — nothing is copied by hand.

Rung 2 · T2

Derive it

Compute from data you already hold, recording the formula. Ketchup dosage comes out of a patent spec; mayonnaise tonnage out of published value ÷ price.

Rung 3 · T3

Cite it

A named source publishes the figure but you cannot verify it independently. Usable, tagged, and never promoted to fact.

Rung 4 · T4

Bound it

No source exists. Declare lo/base/hi, simulate, and rank by influence. The output is a range and a priced research question — not a number someone made up.
